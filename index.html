1 إيه هو Linux أصلاً؟

تخيل إن نظام التشغيل زي بيت 🏠:

  • Windows = بيت جاهز اشتريته — الباب مقفول، مش مسموح تغير في الحوائط، وأنت مش عارف جوه الحيطان في إيه.
  • Linux = بيت مفتوح 100% — تقدر تشوف كل حاجة جواه، تعدل أي حاجة، وتخصصه زي ما تحب بالظبط!

Linux نظام تشغيل مفتوح المصدر (Open Source) — معناه إن كوده متاح للكل، وآلاف المطورين حوالين العالم بيحسنوه كل يوم. وعلشان كده هو الأكثر أمانًا: آلاف العيون بتدقق فيه مش شركة واحدة بس.

🤯 معلومة تصدم الطلبة

Linux مش بس في اللاب بتاعنا — هو في حياتك أكتر مما تتخيل:

2 Windows vs Linux — المقارنة الكبيرة

🪟 Windows

  • 💵 مدفوع (رخصة)
  • 🖱️ كل حاجة بالماوس والواجهات
  • 🔒 كوده مقفول — ما تعرفش جواه إيه
  • 🎯 هدف كبير للفيروسات (أكبر عدد مستخدمين)
  • 👨‍💻 مناسب للاستخدام اليومي والمكتب

🐧 Linux

  • 🆓 مجاني بالكامل
  • ⌨️ كل حاجة ممكن بالأوامر — أسرع وأدق
  • 📖 كوده مفتوح — الكل يقدر يقرأه ويدقق أمانه
  • 🛡️ أكثر أمانًا وثباتًا
  • 🕵️‍♂️ اختيار الهاكرز الأخلاقيين ومحللي الأمن — وده سبب وجودنا هنا!

5 💻 Terminal — لغة المحترفين

يعني إيه Terminal؟ هو نافذة بتكلم فيها الكمبيول بالأوامر مباشرة بدل الماوس. في الأول شكله مخيف، بس لما تتعلمه هتلاقي نفسك أسرع 10 مرات — وده الفرق الحقيقي بين المستخدم العادي والمحترف.

بنية السطر:

kali@sunshine
kali@sunshine:~$ ls
└─ kali = اسم المستخدم | sunshine = اسم الجهاز | ~ = موقعك (Home) | $ = أنت مستخدم عادي (لو # يبقى root!)

📜 الأوامر العشرة الذهبية — بالشرح والتمثيل

1️⃣ pwd — أنا فين؟

kali@sunshine:~$ pwd
/home/kali
# يعني: أنا واقف في مجلد الـ home بتاع kali

💡 زي ما تفتح خرائط جوجل وتشوف "موقعك الحالي" — أول سؤال تسأله لأي محترف في أي نظام.

2️⃣ ls — اعرضلي اللي في المكان ده

kali@sunshine:~$ ls
Desktop Documents Downloads Pictures
kali@sunshine:~$ ls -l
drwxr-xr-x 2 kali kali 4096 Oct 8 10:30 Desktop

💡 ls = عرض عادي | ls -l = عرض بتفاصيل (الحجم، التاريخ، الصلاحيات) | ls -a = اعرض حتى الملفات المخفية 🕵️

3️⃣ cd — تنقل بين المجلدات

kali@sunshine:~$ cd Desktop # ادخل على سطح المكتب
kali@sunshine:~/Desktop$ cd .. # ارجع خطوة للخلف
kali@sunshine:~$ cd / # روح لأصل النظام كله
kali@sunshine:/$ cd ~ # ارجع لبيتي (Home)

💡 cd زي "الأنابيب السرية" في ألعاب الفيديو — بتتنقل بين الغرف فورًا!

4️⃣ و 5️⃣ mkdir و touch — إنشاء مجلد وملف

kali@sunshine:~$ mkdir SunshineLab # أنشئ مجلد جديد
kali@sunshine:~$ cd SunshineLab
kali@sunshine:~/SunshineLab$ touch report.txt # أنشئ ملف فاضي
kali@sunshine:~/SunshineLab$ ls
report.txt

6️⃣ و 7️⃣ nano و cat — اكتب واقرأ الملفات

kali@sunshine:~$ nano report.txt
# يفتح محرر نصوص جوه الترمينال — اكتب: "My first Kali session!"
# اضغط Ctrl+O للحفظ ثم Enter، و Ctrl+X للخروج
kali@sunshine:~$ cat report.txt
My first Kali session!

💡 nano = دفترك للكتابة | cat = يقرألك الملف بصوت عالي (يطبع محتواه)

8️⃣ و 9️⃣ و 🔟 cp و mv و rm — انسخ، انقل، امسح

kali@sunshine:~$ cp report.txt backup.txt # انسخ الملف
kali@sunshine:~$ mv backup.txt old.txt # انقل أو أعِد تسمية
kali@sunshine:~$ rm old.txt # امسح
kali@sunshine:~$ clear # نضف الشاشة
⚠️
تحذير المبتدئين رقم 1: مفيش "سلة مهملات" في Terminal! rm بيمسح للأبد.
ومفيش أسوأ من rm -rf — تلمسها غير وهي بتخصوص مستنداتك، فخليك مركّز! 😅

🗣️ راجع مع نفسك (أسئلة المراجعة السريعة)

  1. يعني إيه نظام مفتوح المصدر، وإيه الفرق بينه وبين المغلق؟

  4. ليه لازم ناخد بالنا من أمر rm؟
  5. ليه بنشتغل داخل VirtualBox ومش مباشرة على الجهاز؟
